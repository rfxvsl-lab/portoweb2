## 🆘 Troubleshooting

### **Mobile Menu not working?**
- Check DevTools (F12) for errors
- Verify data attributes: `data-mobile-menu-btn`, `data-mobile-menu`
- Ensure js/main.js is linked

### **Styles not applying?**
- Clear cache: Ctrl+Shift+Delete
- Verify CSS file path: `css/style.css`
- Check Tailwind CDN is loaded

### **Icons not showing?**
- Check internet connection (Lucide is CDN)
- Verify lucide script is in head
- Check console for errors

### **Smooth scroll not working?**
- Verify `scroll-smooth` in html tag
- Check section IDs match href values
- Ensure js/main.js is loaded
